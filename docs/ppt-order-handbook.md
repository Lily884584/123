# PPT制作手册

这份手册是接单与制作的执行规范。下面是完整 SOP，按当前任务所在阶段执行。

### 技能执行约定

- 将本页作为PPT接单与制作的执行规范；保留以下完整SOP，按当前任务所在阶段执行，不因调用技能就直接制作整套。
- 首轮读取用户提供的材料，输出「需求表、待确认问题、可发客户的话术、建议方案」；将模板情况A/B/C/D写在需求表第一行。未经用户确认，不进入制作。
- 缺少原文件、参考图、客户实拍或数据时，明确列出待补材料；不得编造事实、客户反馈、案例或验收结果。
- 用户确认方案后，默认先做3页样稿；按下文完成并排对比、差距分析与修改选择。样稿获认可后再制作整套。
- 将下文复选框视为每单待核查项目，而不是已完成记录；仅在实际检查后报告通过。不能使用目标电脑上的PowerPoint时，注明「待用户在目标PowerPoint中验收」，不得声称已检查。
- 将下文模型名称和思考强度视为原SOP的参考配置，以当前可选模型为准；不能自行切换模型，不把指定模型作为执行前提。
- 需要经验库、接单台账或复盘库时，先定位用户工作区内对应页面并读取；同名目标不明确时先询问。不能访问时说明缺口，不向公开资料包写入，也不声称已更新。
- 修改台账或复盘前先查重、读取现有内容，只更新本单；仅在用户确认收款后标记已结款。复盘仅使用真实记录，缺失项写「未记录」。
- 审阅阶段按下文交付水印PDF；用户确认定稿后再交付无水印可编辑PPTX。每次交付说明文件版本、完成的核查与待验证事项。

### 怎么用这份SOP（每单开场、收尾各复制一次）

第一次用？先看资料包里的《SOP新手教程》，照着复制话术就能接单。

💡

新开的对话不会自动读这份SOP和经验库，也不会自己更新它们。开场必须 @ 两份文档，收尾必须说「复盘」，经验才会接上。

</aside>

### 各阶段用什么模型

（同一个对话里切换即可，前面的记录都还在）

| 阶段 | 对应流程 | 模型 | 思考强度 | 这一步做什么 |
| --- | --- | --- | --- | --- |
| 理解需求、和我讨论 | 第1–4步 | Opus 5.5 | xhigh | 分析客户需求，列出要问客户的问题，确认修改思路和设计方案；先不制作 |
| 出样稿 | 第5–8步 | Sonnet 5.5 | high | 客户回复后，按确认的方案出样稿、做差距分析；定风格最要审美，不省 |
| 做整套 | 第9–11步 | Sonnet 5.5 | medium | 样稿通过后，做整份PPT并质检；风格已定，照着铺开，省额度 |
| 后续修改（小改） | 第12–13步 | Haiku 5.5 | medium | 改字、换图、调位置、改数据，出源文件 |
| 后续修改（大改） | 第12步 | Sonnet 5.5 | high | 换风格、重做版式、一次加好几页，切回 Sonnet |

💡

模型要我自己在对话框的模型菜单里切换，AI不能自己换。Opus 5.5 加 xhigh 消耗额度最快，只用在理解需求这一步，聊完就切走。

### 开场白

（新对话第一句，用 Opus 5.5 · xhigh 发）

```
按 @PPT制作SOP 和 @PPT经验库 的规则来做。这单是：[比赛/答辩/汇报/产品介绍]，客户要求：[……]。附件是：[原文件/模板/参考图/微信截图]。这一步只理解需求，先不要制作：分析客户需求，列出要问客户的问题（截图里看不清、确定不了的地方也列上），再和我确认修改思路和设计方案。
```

### 客户回复后

（先切到 Sonnet 5.5 再发）

```
客户回复了：[粘贴客户原话或截图]。按我们确认的方案出样稿。
```

### 收尾话术

（客户定稿后；复盘过和没复盘过的对话都能用）

```
收尾这单。按顺序做：1. 查重：先在 @PPT复盘库 里搜本单的复盘页（按客户名、项目名搜）。- 已有：不要新建，只补全下面缺的部分。- 没有：新建一行，标题「复盘｜客户/场景｜项目名」。2. 正文：按 @PPT经验库 第7节复盘模板写，开头一句话总结；内容只用本对话里真实发生的事，没记录的写「未记录」，不要编。3. 属性：填好场景、风格、模板情况、返工轮数、一句话总结、复盘日期，关联台账单子。4. 交付文件：正文最后加「交付文件」小节，把本对话里最终版的PPTX和水印PDF作为附件上传；已经传过的不重复传；文件不在了就写「文件未留存」。5. 台账：更新本单在 @PPT接单台账 的状态和下一步，只改本单这一行。6. 改名：把本对话改名，前面加「✅ 」；已经有的不重复加。7. 汇报：最后告诉我是新建还是补全、补了哪些、哪些没做成。
```

### 每单必做6条（速查）

1. 理解需求后先停下和我讨论，确认问客户的问题和设计方案，不直接制作。
2. 判断模板情况A/B/C/D（第0节）；比赛类先问「大赛风还是简约风」。
3. 先出样稿，不直接做整套。
4. 样稿出来后必做「差距分析」，由我选是否修改（第3.3节）。
5. 交付前看整套缩略图，并在PowerPoint里打开检查一遍。
6. 定稿后复盘，写进经验库。

### 0. 开工第一判断：模板怎么用（最重要，每单必做）

<aside>
💡

动手前必须先回答两个问题：① 客户到底有没有给模板？② 如果给了，模板是「只作参考」，还是「直接把内容填进模板」？这一步判断错，整单都要返工。拿不准就问客户，不许猜。

</aside>

| 情况 | 怎么判断 | 怎么做 |
| --- | --- | --- |
| A. 没有模板 | 客户只给了文字、Word、想法 | 从零设计：按第3节去小红书找参考，再出样稿 |
| B. 模板直接用 | 客户说「用这个模板」「套这个」「照着填」，或模板是单位统一的 | 版式、配色、字体一律不动，只把内容填进去；放不下时先问，不自己改版 |
| C. 模板只作参考 | 客户说「参考这个风格」「做成这种感觉」「类似这样」 | 拆解模板的配色、版式、元素，重新设计，不在原文件上改 |
| D. 原稿美化 | 客户给的是自己做好的PPT，嫌丑 | 保留内容和结构，重做版式；附前后对比图 |
- 判断结果写在需求表第一行：「模板情况：A/B/C/D」。
- 拿不准时发给客户的话术：「您发的这份模板，是需要我们直接把内容填进去、版式不动，还是只参考它的风格、我们重新设计？」
- 没有模板也要问一句：「您有没有喜欢的参考图？没有的话我们来找几套给您选。」
- 坑：【银行汇报】把B误读成了重新设计，返工一整轮。

### 1. 标准流程

1. 放素材：我把微信截图、原PPT、参考图上传到本单的对话里。
2. 理解需求（Opus 5.5 · xhigh）：读完全部素材，输出需求表、疑点、要问客户的问题（截图里看不清、确定不了的地方也列上）和可直接发送的话术；同时在「PPT接单台账」里新建本单。
3. 先停下和我讨论（Opus 5.5 · xhigh）：这一步不制作。和我一起分析客户需求，确认要问客户的问题、修改思路和设计方案；我说「可以了」才进入下一步。
4. 我拍板：去问客户，或让你按默认方案先做。
5. 出样稿（客户回复后，我切到 Sonnet 5.5）：默认3页（客户另有说明除外），用来确认风格。按第3节「样稿制作与自检」执行。
6. 差距分析（必做）：样稿和参考模板（客户给的或我们找的）并排对比，分析差距和改法，然后弹出选项让我选是否修改。按第3.3节执行。选「修改」就改完再比一次，直到我选「不改了」。
7. 自问清单：第3.4节全部通过后，才发客户。
8. 修样稿：根据我转达的客户意见调整，直到客户认可风格。
9. 做整套（Sonnet 5.5）：沿用认可的样式。
10. 质检：逐页渲染，对照第4节交付前核查清单检查。
11. 交付水印版PDF：只发水印版PDF给客户审阅，附「发给客户前要知道的几点」。不发PPT源文件。
12. 客户修改（小改我切到 Haiku 5.5；换风格、重做版式、一次加好几页时切回 Sonnet 5.5）：我把修改意见（截图或文字）发到对话里，你逐条修改、逐条回复，改完质检后再出水印版PDF。小改动只出改动页。循环第11–12步，直到客户确认没问题。
13. 生成源文件：客户确认定稿后，生成无水印可编辑PPTX源文件（元数据已改；用了特殊字体时，我在PowerPoint里嵌入字体后再发），发给客户。
14. 复盘：我说「复盘这单」后，必须在「PPT复盘库」里新建一行（标题「复盘｜客户/场景｜项目名」，填好属性，关联台账单子，开头一句话总结），按经验库第7节复盘模板写，不能只在对话里回复。新规则和踩坑，等我说「整理复盘」时再统一提炼进SOP和经验库。

### 1.1 台账节点：边做边记（AI自动执行，不等结单）

| 节点 | 台账里要改的 |
| --- | --- |
| 出需求表 | 新建本单（先查重），状态「需求确认」，填好客户、场景、接单日期、交付截止、页数、派单编号（如有）、下一步 |
| 发样稿 / 水印版 | 状态改为「等客户反馈」，更新下一步 |
| 收到客户修改 | 修改轮数加1，状态改为对应阶段；在本单页面正文「过程记录」下追加一条 |
| 出无水印源文件 | 状态改为「已定稿」，在本单页面正文写一段结单小结（交付了什么、改了几轮、客户最满意什么） |
| 收款 | 我确认收到钱后，在看板上把卡片拖到「已结款」。「已结款」只在我确认收款时用，AI不自己改 |
- 过程记录每条一行：「YYYY-MM-DD｜节点｜客户原话｜返工原因｜下次怎么避免」。没有返工的节点只写日期和节点。
- 只改本单这一行，不碰别的单。
- 结单：我说「盘点台账」时，最后一条过程记录超过2天没有新动静的，改为「已结单」（只表示这单结束了，不代表收到钱）；一个文件都没交出去的，改为「中止」。我只指出例外。
- 已结单的单子又收到客户修改时，把状态改回对应阶段，修改轮数加1，照常追加过程记录。

### 2. 开工前确认清单

- 用途与受众是什么？
- 模板情况属于A/B/C/D哪一种？（见第0节，必问）
- 页数上限是多少？
- 有没有品牌色、参考图或原模板？
- 数据由谁提供？哪些允许估算？
- 客户的实拍照片够不够？不够就先列清单请客户补，缺的位置留空，不用AI图顶替。
- 截止时间是什么时候？
- 客户是否有特殊限制（如测试要求不能用AI、内部资料要保密）？
- 客户有没有自己喜欢的参考图？没有就由我们从小红书找。
- 比赛类（职规赛、大创赛、教学能力大赛等）必问：要「饱满隆重的大赛模板风」，还是「简约高级风」？

### 3. 样稿制作与自检

流程：找参考 → 按参考出样稿 → 差距分析 → 我选是否修改（可循环）→ 自问清单 → 发客户

### 3.1 找参考（客户没给模板时必做）

1. AI根据客户需求和主题，给出5–8组小红书搜索词，格式为「主题/行业 + 场景 + 风格 + PPT」，从精准到宽泛排列。例：「公益志愿 路演答辩 PPT」「银行 季度分析 PPT」「地产 公司介绍 大气 PPT」。
2. 我去小红书挑2–3套点赞高、一眼高级的模板，截图发到对话里（封面加2–3页内容页）。
3. AI拆解出风格说明：配色、字体字号层级、版式网格、装饰元素、需要按去AI化规则改掉的地方。
4. 选最贴合客户场景的一套做主参考，照着它的风格原创重做，不东拼西凑，不直接复制别人的模板。
5. 定稿或客户夸过的样式记进复盘页，同类单子直接复用。

### 3.2 制作要求去AI味

- 版式要有变化：封面、目录、数据页、图文页、金句页各用一种版式，不要整份都是卡片。
- 敢用大图、大字、大留白。
- 优先用客户实拍或真实图片，少用AI生成图。
- 文案说人话：用客户原话和具体数字，不写口号套话。
- 禁用：圆角卡片、柔和投影、渐变圆圈、①②③圆圈编号、「→」「+」符号、满屏小图标、蓝紫渐变、装饰性英文、XX占位名、每页底部总结通栏、没有实际作用的导航标签、满屏胶囊标签。
- 先删内容再设计：同一个点只在一页讲，重复的页先合并。
- 每页一个主角：一个数字、一张图或一句结论；数据页的数字必须放大。
- 例外：客户明确要大赛模板风时，装饰可以多（书法金字、真人抠图、光效、导航条），但版式仍要有变化、文案不口号化、照片要真实。

### 设计基本功

| 原则 | 做法 |
| --- | --- |
| 对齐 | 所有元素对齐到同一套网格，左右边距统一 |
| 留白 | 不塞满，四周至少留页面宽度的5%–8% |
| 对比 | 标题明显大于正文，重点只用一个强调色 |
| 配色克制 | 每页最多1个主色+1个强调色+黑白灰 |
| 统一 | 同类元素的字号、颜色、间距、图片处理全套一致 |
| 图片质量 | 清晰大图，裁切得当，不拉伸、不糊、不堆小图 |

### 字体与排版（避免AI味字体）

| 场景 | 标题 | 正文 | 感觉 |
| --- | --- | --- | --- |
| 公司汇报 / 银行 / 政务 | 思源宋体 Heavy 或思源黑体 Bold | 微软雅黑 | 稳重 |
| 路演 / 比赛 / 产品发布 | 阿里巴巴普惠体 Heavy、HarmonyOS Sans Black | 阿里巴巴普惠体 Regular | 有冲击力 |
| 国风 / 文化 / 党建 | 思源宋体 Heavy、站酷类书法字（标题转成图片） | 思源宋体 | 文化感 |
| 教学课件 | 思源黑体 Medium | 微软雅黑 | 清晰 |
| 高级 / 杂志风 | 思源宋体 Light 大字号 | 思源黑体 Light | 精致 |
- 不要全篇只用微软雅黑；有参考图时，先识别参考图用的字体，再换成风格接近的免费可商用字体。
- 拉开字号和粗细：标题至少是正文的2–3倍（如54号配16号）；标题用 Heavy/Black，正文用 Regular/Light；重点数字放大，旁边配小字说明。
- 默认左对齐，只有封面、金句页可以居中；正文行距1.3–1.5倍；大字号标题字间距稍微收紧。
- 一页最多2种字体，全套最多3种。
- 禁用：渐变字、发光字、描边字、3D字、装饰性英文小标题、每页标题样式不一致。

### 字体技术与版权

- 只用系统字体（微软雅黑、等线、黑体、宋体、楷体、仿宋）或免费可商用字体（思源黑体、思源宋体、阿里巴巴普惠体、HarmonyOS Sans、OPPO Sans、站酷系列）；不用未授权的方正、汉仪、华康等商用字体。
- 特殊字体二选一：标题转成图片或形状（任何电脑都正常显示，但不能改字）；或定稿后在 PowerPoint 里「文件 → 选项 → 保存 → 将字体嵌入文件」（需 .ttf 版本，.otf 常嵌不进去；「嵌入所有字符」可编辑但文件大）。AI 生成的 PPTX 本身无法嵌入字体。
- 渲染预览和导出 PDF 前，先把用到的字体（.ttf）装进 AI 的环境，否则预览和水印版 PDF 会被替换成别的字体。
- 文本框留余量，防止客户电脑上换行变化导致溢出；发水印版前，在 Windows 的 PowerPoint 里打开源文件检查一遍。

### 3.3 差距分析（每次出样稿后必做）

参考模板可能是客户给的（模板情况B/C），也可能是我们从小红书找的（3.1节）。没有任何参考时，先按3.1节找参考，再做这一步。

### 第1步：并排对比图

- 样稿和参考模板的对应页并排拼成一张图（左参考、右样稿），一页一组，发给我看。

### 第2步：差距表

差距表列项：维度、参考模板怎么做的、样稿现在怎么样、差距（大/中/小）、要做到参考的效果具体怎么改。维度包括：配色、字体和字号层级、版式和网格、装饰元素、图片处理、信息密度和留白、整体精致度。

- 「怎么改」必须具体到能直接执行，例如「标题从28号放大到44号」「证书改成两侧弧形墙」，不写「更高级一些」。

### 第3步：打分和结论

- 按四项打分（1–5分，5分最好）：像参考（风格接近程度）、好看（精致程度）、贴合（符合客户场景和身份）、不像AI。
- 用一句话说明：样稿离参考还有多远，最大的差距是哪一条。
- 修改建议按「对效果影响最大」排序，每条标注改动量（小改/中改/重做）。

### 第4步：弹出选项，让我选

用选择题弹窗问我（没有弹窗时就列出选项，让我回数字），选项固定为：

1. 按建议全部修改
2. 只改其中几条（列出建议，让我勾选）
3. 不改了，进入自问清单准备发客户
4. 换一个参考模板重新对比
- 选1或2：改完重新出并排对比图和差距表，再弹一次选项。
- 四项都达到4分以上时，标注「已达标，建议进入下一步」，但最终由我选。
- 同一页改了3轮还没达标，先停下，按3.5节的干预提示词诊断，不再盲改。

### 3.4 样稿自问清单（每次发样稿前必问）审美

- [ ]  这个样稿AI味重不重？客户会不会一眼看出是AI做的？
- [ ]  审美够不够好看？我愿不愿意把它放进作品集？
- [ ]  和参考图放在一起，差距在哪？

有一项答不上来或答案是否定的，就先改，不发客户。

### 3.5 跑偏时的干预提示词

给了模板，做出来还是很AI，或者越改越偏时使用。核心：先停下、先诊断、先认错，再动手。

### 通用干预

```
先停下，不要继续出图。我们回到起点重新想一遍：1. 复述客户原话：把客户说过的每一句要求列成表，左边是原话，右边是你理解的实际意思。客户重复说过的话单独标出来。2. 重新判断模板情况：A 没有模板 / B 模板直接用 / C 模板只作参考 / D 原稿美化。说明你之前按哪种做的，对不对。3. 诊断AI味来自哪里：逐页指出你上一版哪里像AI，分成两类——- 内容：口号、对仗、排比、套话、像说明书、没有具体数字和真实经历- 视觉：卡片堆叠、版式重复、图标太多、字体没层级、和模板不一致4. 和模板逐项对比：配色、字体、字号层级、版式结构、装饰元素，列出你偏离模板的地方。5. 承认偏差：用一两句话说明你之前哪里想错了。6. 给出修改方案：怎么改、先改哪一页。先只输出以上分析，等我确认后，先改1页给我看，不要一次改整套。
```

### 加强版A：AI味主要在内容上

（接在通用干预后面）

```
这次重点是内容，不是排版。模板不动，版式不动。文案规则：说人话，用第一人称讲真实经过；不对仗、不喊口号、不写金句；一页最多一句结论；保留原稿里的真实数据、原话和过程细节；没有素材的地方标【待补】，不要编。
```

### 加强版B：AI味主要在视觉上

（接在通用干预后面）

```
严格照模板做，不要自己发挥：配色、字体、字号、页边距、标题位置全部和模板一致。去掉所有圆角卡片、阴影、渐变、满屏图标；版式要有变化，敢用大图、大字和留白。改完把你的页面和模板对应页并排拼成对比图，按「像模板、好看、不像AI」三项打分（1–5分），低于4分的继续改。
```

### 用法要点

- 先诊断，不要直接说「重做」。只说「太AI了，重做」，AI多半只是换一套画风，越改越偏。
- 让它复述客户原话。这一步最能把它拉回正轨。
- 先改1页，确认方向对了再改整套，省时间也省额度。

### 3.6 局部换图、加页与视频稿

- 局部修改先列「页码 / 旧对象 / 新对象 / 前景还是背景 / 裁切方式 / 不动项」。客户说「换成这张图」时，不自行推断是替换内容图、铺成背景还是整体换风格。
- 已确认的背景、配色、文字和版式锁定；只改指定范围。新增页面同步总页数、章节编号、目录（若有）、演讲者备注及主讲人分工。
- 演讲稿做两层：上屏为短句和重点，完整原文及讲者分工进备注；如需精简，要说明精简范围，不偷偷删掉原意。
- 新闻图可裁掉无关滚动字幕，但不得裁掉改变原意的上下文；政策要点对应原始出处核验。
- 视频先核对时长、画幅、声音和落点；PPTX嵌入媒体并设置封面与播放方式。PDF只有静态封面，不能当作播放验收；需要展示动态效果时另给预览视频。
- 在交付电脑的PowerPoint中实际单击播放，检查声音、画幅、封面和放映模式；没有完成这一步，只能写「已嵌入，待现场验证」，不能保证「点一下就能播」。
- 制作完成、发给客户、客户定稿、确认收款分开记录。生成了文件不等于客户认可；客户中止也不等于没有制作文件。历史记录和新证据不一致时说明时间与口径，不自行覆盖人工确认的业务状态。

### 5. 场景要点

| 场景 | 核心要求 | 特有风险 |
| --- | --- | --- |
| 产品介绍 | 用品牌色；改变内容的表现形式，不只是换排版；竞品对比时高亮我方 | 内部资料要保密；原图带水印；改动要逐条告知客户 |
| 公司汇报（银行等） | 模板不动，只填数据和分析；用真实的周边商户、小区、同业和利率数据 | 真假数据必须分开标注；模板可能是从别的省份复用来的 |
| 内部会议 | 参考上一期稿子和客户的参考风格；页数受限；数据留空给客户填 | 旧季度内容残留；颜色规则不统一 |
| 竞聘 / 设计测试 | 最高审美；交付截图加作品展示长图 | 可能要求不能用AI；字体需要安装或嵌入 |
| 比赛路演 | 动画、视频、照片替换；多轮细改 | 文件过大；照片的地点是否真实 |
| 教学课件 | 简洁白底；公式格式准确；按单击顺序出现的动画 | 手写稿辨认；分式等排版细节 |
| 招商推介 | 封面加区位示意图 | 缺实景图时留位置给客户补 |

### 6. 技术注意

- 预览环境可能缺字体，显示效果以客户的Windows电脑为准。
- 原文件过大读不进来时，先告诉我，再商量拆分处理。
- 成品超过30MB时，先压缩图片；还是太大就拆分文件，并说明字体嵌入会被去掉。

### 7. 踩坑记录（持续更新）

- 【银行汇报】把「填模板」误读成「重新设计」，返工一整轮。
- 【银行汇报】数据是编的，网格图用了别的地区，被要求换成网点周边的真实商户。
- 【内部会议】改完没有真正保存，桌面上一直是旧版，导出水印版时才发现。
- 【保险汇报】文件作者显示为PptxGenJS，暴露了制作工具。
- 【景区宣传】客户选的照片疑似拍的是外地，不是客户所在的城市。
- 【韩语】【长视频】【培训结课】样稿太素，客户要求元素丰富一些。无指定风格时，样稿不要只做白底加文字，要有配图、数据图或层次。
- 【产品路演】样稿单页没问题，整套22页内容重复（痛点讲2遍、方案讲3遍）、每页同一模板加底部总结通栏，整体很丑。交付前必须看整套缩略图。
- 【职规赛】客户要饱满隆重的大赛模板风，按简约规则做成了素的。比赛类开工前先问风格。
- 【职规赛】模板自带的别的学校的校徽没换掉。
- 【英文稿】文字语言是英文，客户打开满屏红色波浪线，还追问是不是WPS做的。
- 【急单】对接人转达「老板喜欢这个风格」，样稿改到v6。开工先问谁拍板。
- 【班委竞选】自己加的口号式标题被嫌AI，改成客户原句加真实截图后才通过。
- 【职规赛·奖状墙】证书先做成斜摆透视，又改成平铺网格，都被嫌乱或不像；客户发了参考图后改成两侧弧形墙，一轮就过了。风格描述两轮还不对，直接要参考图。
- 【职规赛·奖状墙】预览环境没有微软雅黑，说明字在预览里被挤成两行，误以为是排版问题。渲染前先装字体。
- 【韩语】外语稿只设了西文字体，韩文在预览和PDF里被换成别的字体；LibreOffice导出PDF时韩文标点前多出空格。外语稿要同时设西文和东亚字体（韩语用Malgun Gothic），导出PDF前修正标点间距并逐页看。
- 【韩语】先给了带水印的PPTX，水印是文本框，客户能直接删。水印版只发PDF。
- 【韩语】客户说「随便编」，经历、评价、评分都是代写的。交付时列出代写清单，请客户换成自己的真实信息。
- 【银行分析】客户反馈新增不良页需要更直观；改为总量→贷款类型→担保方式分层拆解，面积表达占比，图内标明比例并配金额、笔数。银行分析页先把数据关系画清楚，避免只靠图例和段落解释。
- 【主题演讲】「换图」没有先区分内容图和背景，导致替换图、铺背景、恢复抽象背景反复切换。局部改稿先列对象、不动项和裁切方式。
- 【主题演讲】整套由6页增至7页并嵌入两段视频：加页要同步编号与备注；媒体结构检查不等于PowerPoint放映实测，PDF不能播放视频。
- 【主题演讲】本对话已有整套文件，台账却仍写「样稿阶段、没有成品」。复盘要补制作事实，但客户中止、定稿和收款状态各自保留证据，不混写。
- 【主题演讲】曾把PDF水印说成「去不掉」。水印只能降低直接复用风险，PDF及图片化PDF都不能保证绝对无法去除。
